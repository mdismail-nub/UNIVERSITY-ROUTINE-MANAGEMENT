University Routine Management System

This is a console-based C++ project for managing university course information. Currently, the project has an Admin Portal with a Course Management section where users can add, view, update, and delete courses.

Each course contains a Course ID, Course Code, Course Name, and Credit. The project also includes basic input validation and a limit on the number of courses that can be stored.

This is the first part of the project. More features, such as routine management and data storage, will be added gradually.
